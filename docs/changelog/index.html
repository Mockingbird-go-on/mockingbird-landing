Changelog

Коротко: ниже — история релизов Mockingbird. Текущая версия — v1.0.2.0 от 24.09.2026. Ссылки ведут на соответствующий выпуск в GitHub.

v1.0.2.0 — 24.09.2026 · первый публичный релиз

  • Первый публичный релиз Mockingbird для Windows и Linux.
  • Локальное распознавание речи на faster-whisper (large-v3-turbo), ускорение CUDA.
  • Adaptive VAD (Silero) — автоматическое определение речи.
  • База знаний: загрузка PDF-резюме, индексация и контекст для LLM.
  • Ответы LLM в реальном времени со стримингом.
  • Режим Невидимка: окно скрыто при шаринге экрана и стриминге.
  • Фонетическая коррекция технических терминов в живом черновике.
  • Вкладки Интервью / Резюме / Лог.
  • Поддержка Windows и Linux.
