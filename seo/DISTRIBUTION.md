## Каналы по приоритету

### Уровень 1 — быстро, эффект через дни

1. **GitHub-экосистема**
   - README приложения: гифка-демо, скриншоты, бейджи, раздел Links (сайт, docs, статьи, Telegram).
   - PR в awesome-списки: `awesome-ai-tools`, `awesome-selfhosted`, `awesome-interview`.
   - GitHub Discussions / Show HN на GitHub.
2. **Telegram**
   - Собственный канал: закрепить пост со ссылкой на `/articles/questions/`.
   - Бартер/посты в каналах про карьеру, DevOps, собеседования (продукт бесплатный — легко договариваться).
3. **Хабр Q&A / Stack Overflow (ru)**
   - Отвечать на реальные вопросы про собеседования со ссылкой на статьи (не на продукт — иначе бан).

### Уровень 2 — средний труд, эффект через недели

4. **Reddit**: r/devops, r/ITCareerQuestions, r/cscareerquestionsEU — формат «сделал/спрашиваю мнения», не реклама; читать правила сабреддитов.
5. **Habr / VC.ru / Tproger**: статья-кейс «Как я сделал ИИ-помощника для собеседований» (технический разбор). Лучший генератор ссылок и AI-упоминаний в рунете.
6. **YouTube/Twitch-блогеры** про собеседования: бесплатные обзоры за ранний доступ.
7. **Product Hunt / Product Radar**: разовый запуск — пик трафика + постоянная ссылка.

### Уровень 3 — долгая игра (месяцы)

8. **Wikidata**: запись о проекте после 3–5 независимых упоминаний.
9. **Каталоги AI-инструментов**: theresanaiforthat, toolify, futurepedia — анкеты со ссылками.
10. **Партнёрства**: курсы подготовки к собеседованиям, боты по вакансиям.

## Правила

1. Ссылки ведут на **статьи и хаб вопросов**, не на голый лендинг — там контент, который цитирует AI.
2. Единая формулировка сущности везде: **«Mockingbird — ИИ-помощник на собеседовании»** (см. SEO.md).
3. Дифференциатор — честность: прокторинг, ограничения, приватность. Площадки такое пропускают, рекламу — нет.
4. Темп: **2–3 упоминания в неделю стабильно** лучше 20 за один день.
5. Приоритет ссылок: `/articles/questions/`, `/articles/neural-network-for-interview/`, `/articles/ai-assistant-for-interviews/`, затем `/docs/install/`.
