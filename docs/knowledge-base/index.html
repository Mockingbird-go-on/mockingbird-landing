База знаний

База знаний — это контекст, на который опирается LLM при построении ответа. Обычно это ваше PDF-резюме и краткие заметки по технологиям.

Загрузка резюме

  1. Откройте вкладку Резюме.
  2. Нажмите Загрузить PDF и выберите файл.
  3. Дождитесь индексации — приложение покажет число блоков.
Резюме обрабатывается локально через pypdf — файл никуда не отправляется.

Как это влияет на ответы

При вопросе интервьюера релевантные блоки базы знаний подмешиваются в контекст LLM. Чем точнее и структурированнее резюме, тем конкретнее ответы.

  • Указывайте технологии и проекты с деталями (что делали, какими инструментами).
  • Разбивайте по секциям: Опыт, Стек, Проекты.
  • Избегайте изображений-сканов без текстового слоя.

Обновление знаний

Чтобы заменить контекст — повторно загрузите новый PDF: старые блоки переиндексируются.
