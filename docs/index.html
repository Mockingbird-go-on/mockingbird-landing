Mockingbird docs

Mockingbird — десктопный офлайн-ассистент для технических интервью: локальное распознавание речи, база знаний из PDF-резюме и ответы LLM в реальном времени. Работает на Windows и Linux, наружу уходит только запрос к LLM.
