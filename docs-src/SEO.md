Рабочий документ. В продакшене не нужен — источник для мета-тегов, текстов и доков.

## Позиционирование

**Офлайн-ассистент для технических интервью**: локальное распознавание речи,
база знаний из PDF-резюме, ответы LLM в реальном времени. Windows и Linux, open source.
