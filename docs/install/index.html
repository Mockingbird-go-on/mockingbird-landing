Установка

Mockingbird — десктопное приложение на PySide6. Скачайте сборку для своей ОС со страницы релизов.

Требования

  • Windows 10/11 или Linux (x86_64).
  • GPU NVIDIA с CUDA — для ускорения распознавания (опционально, но рекомендовано).
  • ~2–4 ГБ на диске под модель faster-whisper large-v3-turbo.

Windows

  1. Скачайте Mockingbird-setup.exe из последнего релиза.
  2. Запустите установщик и следуйте шагам мастера.
  3. Запустите приложение из меню «Пуск».

Если CUDA не обнаружена, приложение автоматически перейдёт на CPU — распознавание будет работать, но медленнее.

Linux

  1. Скачайте Mockingbird.AppImage.
  2. Сделайте файл исполняемым и запустите:
chmod +x Mockingbird.AppImage
./Mockingbird.AppImage

Первый запуск

  1. Проверьте индикатор устройства в тулбаре: GPU или CPU.
  2. Загрузите PDF-резюме на вкладке Резюме (опционально).
  3. Нажмите Старт и говорите — черновик появится на вкладке Интервью.

Обновление

Приложение проверяет новые релизы при запуске. Вручную — настранице релизов.
